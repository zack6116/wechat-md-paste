# 用 Markdown 写公众号

这是一段同时包含**加粗**、*斜体*和`行内代码`的正文。

## 你可以带走什么

- 标题、列表和引用会变成带样式的 HTML
- 图片按文中的位置插入
  - 本地图片要和 Markdown 放在同一个目录里一起上传

> 扩展只把内容写入草稿，不会替你点击发表。
