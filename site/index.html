让模型直接写出可导入的稿

Skill 名字是 wechat-mp-markdown。它只生成这个扩展能导入的 Markdown，图片用自动上传的写法，不用 HTML，也不用 Obsidian 双链。

Claude 和 Codex 安装

npx skills add zack6116/wechat-mp-markdown -a claude-code -a codex -g -y

需要本机有 Node.js。这条命令会把 skill 装到 Claude Code 和 Codex。

下载 Skill 压缩包 GitHub 仓库

不用命令时，解压后把 wechat-mp-markdown 文件夹放到 Claude 的 ~/.claude/skills/，或 Codex 的 ~/.agents/skills/。

第一次使用

  1. 从 GitHub 下载扩展，解压。
  2. 打开 chrome://extensions，打开开发者模式，选择「加载已解压的扩展程序」。
  3. 登录公众号并打开一篇图文草稿。成功标志：编辑区右上角出现「导入 Markdown」。
  4. 拖入 .md。有本地图片时，在扩展弹出的小窗口里选择图片所在文件夹。

还没有上架 Chrome 网上应用店。安装后有 14 天完整试用。

它怎样工作

Markdown 在浏览器里转成带样式的 HTML。本地图片从你授权的文件夹读取，网络图片在你点允许后下载。上传由已经打开的公众号编辑页发出，扩展不读取 Cookie，也不把文章发到作者的服务器。

使用边界

  • 只写入草稿，不会自动发布或群发。
  • 试用结束后，免费版每篇最多 3 张图片，不能授权本地文件夹，文末保留一句提示。
  • Pro 为 ¥19/月或 ¥99/年。扩展里没有支付，Key 由作者发给你，并在本机校验。
  • 支持 JPG、PNG、GIF、WebP。超过 8MB 会跳过。不接收 SVG、内网地址或带账号密码的网址。
  • 公众号编辑器改版后，导入可能失败，直到更新扩展里的编辑器适配。
  • 尚未选择开源许可证，版权保留。可以自己加载使用。
