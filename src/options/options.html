使用指引

  1. 打开公众号文章图文编辑页（不是贴图），点「创作」旁边的「导入 Markdown」。
  2. 把文章目录拖进面板。目录里要有 .md 和 images。只上传 Markdown 时不读取本地图片。
  3. 图片写成 ![说明](images/01.png) 或公网 https 地址。本地图片从这次上传的目录里取。
  4. 也可以在正文 Ctrl+V。Skill 的安装和下载在 宣传页。

常见问题

贴图能用吗？不能。只支持「新的创作 → 文章」图文，不支持贴图（createType=8）。

会自动发布吗？不会。扩展只写入草稿。

图片没传上去？本地图片要和 Markdown 在同一个目录里一起上传。只上传 Markdown 时不会读以前选过的文件夹。公网 https 图片仍会上传。请确认这篇草稿仍然打开着。

试用天数不对？清除扩展数据会重新计算 14 天。
