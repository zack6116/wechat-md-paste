## 权限怎么填

| 权限 | 商店里要写的目的 |
| --- | --- |
| storage | 在本机保存试用时间和 License Key |
| 主机权限 mp.weixin.qq.com | 在图文编辑页显示导入按钮，并把内容写入当前草稿 |
| 可选的网站访问 | 用户确认后，下载 Markdown 里引用的网络图片 |

## 隐私问卷草稿

- 不收集用户身份，不出售数据。
- 文章内容不发送到开发者服务器。
- 网络图片仅在用户允许后，从图片原地址下载，再上传到用户当前打开的公众号草稿。
- License Key 只存在用户浏览器里。

问卷要以提交当次的实际代码为准，逐项再核一次。
